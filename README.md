# Tarnished

An offline-capable Elden Ring quest, boss, and item tracker.

## GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, **main**, and **/ (root)**, then save. The site will be at https://ressik.github.io/Tarnished/ once deployment succeeds.

GitHub Free requires a public repository for Pages. Eligible paid plans support Pages from private repositories; the website itself is generally public.

Open the site in Chrome on Android, wait for **Ready offline**, then choose **Install Tarnished** or **Add to home screen → Install**.

Export progress from the previous HTML tracker and import it here. Saves do not automatically transfer between domains or local files.
